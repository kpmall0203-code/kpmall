실행되는 원본은 Apps Script 프로젝트이고, 이 저장소는 기록·검토용입니다.

- **`docs/인수인계_2026-09-16_광고자동화_전체.md` — 전체 인수인계서. 이어받는 사람은 이것부터.**

- `apps-script/00_기획서.gs` — 광고 기능의 목적과 지켜야 할 규칙. **코드를 고치기 전에 먼저 읽는다.**
