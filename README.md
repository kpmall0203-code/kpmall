# kpmall — 사입도우미 (Google Apps Script)

구글 시트 「아마존 최저가 도움 광고 데이터 관리」에 묶인 Apps Script 소스의 거울입니다.
실행되는 원본은 Apps Script 프로젝트이고, 이 저장소는 기록·검토용입니다.

- `apps-script/00_기획서.gs` — 광고 기능의 목적과 지켜야 할 규칙. **코드를 고치기 전에 먼저 읽는다.**
- `apps-script/10_메뉴.gs` — 메뉴 구조 (가격관리 → 리프라이싱 · 📣 광고 · 분석 · 데이터 갱신 · 설정)
- `apps-script/72*.gs` — 광고 (기준 → 재배분 → 계획 → 생성 → 켜기 → 검색어 → 반영)
- `apps-script/77_설명서.gs` — 시트 안 [설명서] 탭을 만드는 내용. 메뉴 순서 그대로.

파일은 알파벳순으로 적재됩니다 (Apps Script 규칙). 전역 이름이 겹치면 뒤의 것이 이깁니다.
